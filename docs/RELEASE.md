# Выпуск Interview Loom

## Предварительные условия

- все изменения находятся в защищённой ветке и прошли `CI`;
- `APP_VERSION` в `app/metadata.py` увеличен по Semantic Versioning;
- `CHANGELOG.md` обновлён;
- GitHub Pages использует `GitHub Actions` как source;
- signing credentials заданы только в GitHub Actions Secrets.

## Beta-релиз без подписи

1. Запустите workflow `Desktop release` вручную и укажите тег вида `v1.0.0`.
2. Дождитесь успешных jobs `tests`, `macos-arm64`, `windows-x64`, `publish`.
3. Проверьте SHA-256 и `.manifest.json` в созданном GitHub Release.
4. Скачайте оба установщика на чистые тестовые устройства и выполните smoke-сценарий.
5. Только после проверки пометьте релиз как основной в описании продукта.

## Подписанный production-релиз

Настройте secrets, перечисленные в README. Workflow подписывает `.app` до создания DMG, нотарифицирует DMG и подписывает Windows EXE/Setup. Никогда не добавляйте P12/PFX или пароли в репозиторий и артефакты workflow.

Создание релиза по Git tag:

```bash
git tag v1.0.0
git push origin v1.0.0
```

## Обязательная ручная проверка

- приложение запускается без Python и Terminal;
- камера, микрофон и запись экрана запрашивают разрешения только после действия пользователя;
- готовый WebM/MP4/MOV отображается в preview и загружается;
- без Gemini key сохраняется транскрипция;
- сохранение ключа не показывает его после запроса;
- существующая база открывается после обновления;
- лендинг, privacy, terms, support и обе download-ссылки доступны через HTTPS.

## Откат релиза

Не удаляйте неудачный релиз: пометьте его как pre-release и опубликуйте исправленную patch-версию. Лендинг использует `releases/latest`, поэтому после публикации стабильной patch-версии ссылки переключатся автоматически.
