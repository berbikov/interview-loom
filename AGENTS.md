# Правила работы над проектом

## Область проекта

Interview Loom — FastAPI MVP для записи и последующего анализа тренировочного видеоинтервью. Это не помощник для скрытого получения ответов во время реального собеседования. Реализация ведётся небольшими этапами согласно `PLAN.md`.

## Код

- Имена переменных, функций, классов и модулей — на английском языке.
- Пользовательский интерфейс и сообщения пользователю — на русском языке.
- Для публичных функций и границ модулей обязательны осмысленные type hints.
- Не использовать `Any`, если тип можно выразить точнее.
- Docstrings добавлять только для неочевидных контрактов и решений.
- Не смешивать HTTP-слой, работу с базой и внешние AI-интеграции.
- Ошибки внешних сервисов не должны раскрывать секреты или внутренние детали.
- В тестах запрещены реальные вызовы Gemini API.
- JavaScript используется только для браузерных медиафункций и необходимого взаимодействия интерфейса.

## Данные и безопасность

- Не коммитить `.env`, API-ключи, SQLite-файлы и загруженные видео.
- Проверять MIME-тип и размер файла на сервере.
- Не доверять имени загружаемого файла при формировании пути хранения.
- Публичный доступ к записи осуществлять по случайному `public_id`, а не по внутреннему ID.

## Проверки

- Перед завершением этапа запускать весь набор `pytest`.
- Проверять импорт приложения и health-check локальным запуском Uvicorn.
- Ошибки тестов исправлять до передачи результата.
- Не выполнять merge без прямой команды пользователя.
