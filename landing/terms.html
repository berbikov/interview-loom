Условия использования

Interview Loom предназначен для самостоятельной тренировки и анализа ответа после записи. Приложение нельзя использовать для скрытого получения подсказок, нарушения конфиденциальности собеседования или записи людей без их согласия.

AI-оценка носит рекомендательный характер и может содержать неточности. Пользователь самостоятельно проверяет рекомендации и отвечает за соблюдение правил работодателя, законодательства и условий Gemini API.

Пользователь отвечает за сохранность своего API key и локальных данных. Приложение предоставляется без гарантии трудоустройства или конкретного результата собеседования.
