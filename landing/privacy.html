Interview Loom
Документы

Политика приватности

Коротко: публичный лендинг не принимает видео, не требует регистрации и не хранит данные интервью.

Локальные данные

Desktop-приложение хранит видео, расшифровки, модели Whisper и SQLite-базу только в пользовательском каталоге приложения. Эти данные не отправляются разработчику.

Gemini

Если пользователь самостоятельно добавил Gemini API key и запустил анализ, в Google Gemini передаются расшифровка, вопрос, должность и необязательное описание вакансии. Само видео не передаётся. Обработка Google регулируется условиями аккаунта и API пользователя.

Секреты и журналы

Gemini API key хранится системным хранилищем учётных данных macOS или Windows. Ключ не сохраняется в SQLite, HTML, JavaScript или журнале приложения.

Удаление

Пользователь контролирует локальные файлы и может удалить данные приложения средствами операционной системы. Не прикладывайте секреты, видео или расшифровки в публичное обращение.
