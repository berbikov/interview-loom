# История изменений

Все заметные изменения Interview Loom документируются в этом файле. Версии следуют Semantic Versioning.

## 1.1.0 — 2026-08-09

### Добавлено

- AI Chat с контекстом расшифровки и AI-разбора;
- история диалога в SQLite и отдельная Alembic-миграция;
- автоматическая установка WebView2 Runtime на Windows.

### Изменено

- Windows installer переименован в `Interview-Loom-Setup-x64.exe`;
- Windows CI проверяет установку, запуск и стандартный uninstall.

## 1.0.1 — 2026-08-09

### Исправлено

- добавлено безопасное разрешение камеры и микрофона для локального адреса macOS-приложения;
- если встроенный WebKit не предоставляет MediaRecorder, студия записи открывается в системном браузере без ручного запуска сервера;
- сообщение «браузер недоступен» заменено на понятный сценарий продолжения записи.

## 1.0.0 — 2026-08-09

### Добавлено

- запись камеры, микрофона и экрана через MediaRecorder;
- загрузка готовых WebM, MP4 и MOV;
- локальная транскрибация через faster-whisper;
- структурированный Gemini-анализ с Pydantic-валидацией;
- персональный Gemini key в системном keyring desktop-приложения;
- macOS/Windows desktop runtime и installer pipelines;
- статический публичный лендинг, политика приватности и условия использования;
- Alembic-миграции с резервным копированием SQLite;
- автоматические тесты, GitHub Pages и GitHub Releases.

### Безопасность

- проверка MIME-типа, размера и сигнатуры медиаконтейнера;
- UUID-имена файлов и отсутствие абсолютных путей в API;
- same-origin защита небезопасных HTTP-методов и security headers;
- секреты, локальные базы и пользовательские видео исключены из Git и сборок.
